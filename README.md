# Pad Project

这是一个用于临时代码编写、测试、便签记录以及小工具开发的通用工作区（Pad）。

## 📁 目录结构

- `tasks.md` - 项目任务管理与进度追踪
- `CLAUDE.md` - Claude 的项目开发规范与命令指南
- `gemini.md` - Gemini 的项目开发规范与命令指南（与 CLAUDE.md 同步）

## 🛠️ 常用操作与指南

由于本工作区具有通用性，在新建具体的子模块或文件时，请遵守以下原则：
1. **简单至上**：编写满足需求的最简代码，避免过度设计。
2. **规范同步**：如果在开发过程中总结了非显而易见的运行命令或技术限制，应及时更新 `CLAUDE.md` 与 `gemini.md`。
3. **任务追踪**：如果有复杂的多步任务，使用 `tasks.md` 进行记录与状态更新。
